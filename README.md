## 🇷🇺 Описание (RU)

Добро пожаловать в мой сборник схем для **Mindustry**! Здесь собраны проверенные чертежи для автоматизации производства, логики и оборонительных систем.

### 📥 Как импортировать схему в игру:
1. Выберите нужную схему в таблице ниже.
2. Скопируйте всю строку из столбца **Код (Base64)** (на GitHub в конце строки кода появится кнопка «Скопировать»).
3. Откройте Mindustry ➔ **Схемы** ➔ **Импорт схемы** ➔ **Из буфера обмена**.

## 🇬🇧 Description (EN)

Welcome to my personal collection of **Mindustry** schematics! Here you can find various blueprints for production, logic, and defense systems.

### 📥 How to import a schematic into the game:
1. Choose the schematic you need from the table below.
2. Copy the entire string from the **Code (Base64)** column (GitHub will show a convenient "Copy" button at the end of the code block).
3. Open Mindustry ➔ **Schematics** ➔ **Import schematic** ➔ **From clipboard**.
